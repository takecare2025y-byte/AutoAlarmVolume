# Auto Alarm Volume Keeper

## How to Build APK in Android Studio
1. Extract this ZIP folder.
2. Open Android Studio -> **File > Open** -> Select the extracted `AutoAlarmVolumeKeeper` folder.
3. Wait for Gradle Sync to finish automatically.
4. Go to **Build > Build Bundle(s) / APK(s) > Build APK(s)** to generate `app-debug.apk`.
